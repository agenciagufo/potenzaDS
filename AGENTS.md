# Instruções para agentes de IA

Este repositório é o design system da **Potenza Motos Elétricas** (Serafina Corrêa, RS).

Antes de criar qualquer material (post, carrossel, story, anúncio, página, documento):

1. Leia `templates/av-design-system/av-design-system-spec.md`: cores, fontes, logos, tom de voz e restrições de comunicação. É a fonte da verdade.
2. Leia `GUIA-PRODUCAO.md`: formatos, grade, estruturas de peça e checklist.
3. Use só os logos de `templates/av-design-system/images/`. Use `*-white` em fundo escuro e `*-black` em fundo claro. Nunca redesenhe, recolora ou distorça o logo.

Regras que não podem ser quebradas:
- Paleta: `#5AF205` (destaque), `#000000` (fundo), `#2E7D00` (verde para texto em fundo claro), `#A6FF4D` (realce pontual).
- Fontes: Saira (títulos) e Inter (texto).
- Ícones em cor chapada, sem gradiente.
- Não afirmar "sem CNH" ou "sem emplacamento" para modelo sem classificação de autopropelido confirmada.
- Não direcionar comunicação de venda a menores de 18 anos; falar com os pais.
- Contato oficial: WhatsApp (54) 98438-7607.

O HTML em `templates/av-design-system/` é referência visual para pessoas; para regras, prefira o spec em Markdown.
